# Stage 3: Pipeline Implementation

## 1. Executive Summary

This document defines **Stage 3** of the Safe Generation feature implementation, focusing on creating a user-friendly pipeline interface for safe text generation. This stage makes safety features easily accessible to end users through the familiar transformers pipeline API.

**Important**: This document represents a complete stage of development. The phases listed below (Phase 1, 2, 3, 4) are implementation steps to complete this stage, not separate stages requiring new documents.

**Scope**: Create `SafeTextGenerationPipeline`, register it with the pipeline system, and provide convenient safety presets.
**Goal**: Enable simple, one-line safe text generation through `pipeline("safe-text-generation")`.
**Timeline**: 10-14 hours across 4 phases.

- **Secondary**: Register new task type in pipeline system with proper defaults
- **Tertiary**: Use existing safety level presets (strict/moderate/lenient) from Stage 1/2
- **Non-Goal**: Advanced features like conversation tracking (Stage 5) or custom safety models

### Design Note: Threshold Configuration

**Important**: Toxicity classifiers lack standardization in confidence scores. The preset thresholds (0.5/0.7/0.9) should be treated as starting points that may require tuning based on:
- The specific safety model used (unitary/toxic-bert vs s-nlp/roberta_toxicity_classifier)
- The application domain and risk tolerance
- User feedback and observed false positive/negative rates

Therefore, the pipeline design emphasizes **easy threshold customization** through both:
1. Simple threshold override parameters (`toxicity_threshold=0.6`)
2. Full custom configuration for advanced use cases

This allows users to quickly adjust sensitivity without deep knowledge of the safety infrastructure.

## 3. Architecture & Design

### Core Component: SafeTextGenerationPipeline

The pipeline will inherit from `TextGenerationPipeline` and add safety-specific functionality:

```python
from transformers.pipelines.text_generation import TextGenerationPipeline
from transformers.generation.safety import SafetyConfig, BasicToxicityChecker
from typing import Any, Dict, List, Optional, Union

class SafeTextGenerationPipeline(TextGenerationPipeline):
    """
    Safe text generation pipeline with built-in safety checking.

    This pipeline extends TextGenerationPipeline with automatic safety checks
    to filter harmful, toxic, or inappropriate content during generation.

    Example:
        >>> from transformers import pipeline
        >>> pipe = pipeline("safe-text-generation", model="gpt2")
        >>> outputs = pipe("Hello, I think")
        >>> # Output will be automatically checked for safety violations

    Args:
        model: Model instance or path to pretrained model
        safety_config: SafetyConfig instance or dict with safety settings
        safety_level: Preset safety level ("strict", "moderate", "lenient")
        **kwargs: Additional arguments passed to TextGenerationPipeline
    """

    def __init__(
        self,
        model,
        safety_config: Optional[Union[SafetyConfig, Dict[str, Any]]] = None,
        safety_level: Optional[str] = "moderate",
        **kwargs
    ):
        super().__init__(model=model, **kwargs)

        # Initialize safety configuration
        if safety_config is None:
            # Use preset based on safety_level
            self.safety_config = SafetyConfig.create_default(safety_level)
        elif isinstance(safety_config, dict):
            self.safety_config = SafetyConfig.from_dict(safety_config)
        else:
            self.safety_config = safety_config

        # Validate configuration
        self.safety_config.validate()

        # Initialize safety checker (lazy loading)
        self._safety_checker = None
        self._safety_initialized = False

    def _ensure_safety_initialized(self):
        """Lazy initialization of safety checker to avoid loading models unnecessarily."""
        if self._safety_initialized:
            return

        if self.safety_config.enabled and "toxicity" in self.safety_config.checkers:
            try:
                from transformers.generation.safety import BasicToxicityChecker
                self._safety_checker = BasicToxicityChecker(
                    model_name=self.safety_config.toxicity_model,
                    threshold=self.safety_config.thresholds.get("toxicity", 0.7),
                    device=self.device
                )
                self._safety_initialized = True
            except Exception as e:
                logger.warning(f"Failed to initialize safety checker: {e}. Safety checking disabled.")
                self.safety_config.enabled = False

    def _sanitize_parameters(
        self,
        safety_config=None,
        safety_level=None,
        toxicity_threshold=None,
        return_safety_metadata=None,
        **kwargs
    ):
        """Extract safety-specific parameters from kwargs."""
        preprocess_params = {}
        forward_params = {}
        postprocess_params = {}

        # Handle safety configuration updates
        if safety_config is not None:
            if isinstance(safety_config, dict):
                self.safety_config = SafetyConfig.from_dict(safety_config)
            else:
                self.safety_config = safety_config
            self._safety_initialized = False  # Force re-initialization

        if safety_level is not None:
            self.safety_config = SafetyConfig.create_default(safety_level)
            self._safety_initialized = False

        # Allow easy threshold override without full config
        if toxicity_threshold is not None:
            if not isinstance(self.safety_config.thresholds, dict):
                self.safety_config.thresholds = {}
            self.safety_config.thresholds["toxicity"] = toxicity_threshold
            self._safety_initialized = False  # Force reinit with new threshold

        # Safety metadata in output
        if return_safety_metadata is not None:
            postprocess_params["return_safety_metadata"] = return_safety_metadata
        else:
            postprocess_params["return_safety_metadata"] = self.safety_config.return_metadata

        # Get parent class sanitized parameters
        parent_preprocess, parent_forward, parent_postprocess = super()._sanitize_parameters(**kwargs)

        # Merge with parent parameters
        preprocess_params.update(parent_preprocess)
        forward_params.update(parent_forward)
        postprocess_params.update(parent_postprocess)

        # Add safety_config to forward parameters
        forward_params["safety_config"] = self.safety_config

        return preprocess_params, forward_params, postprocess_params

    def __call__(self, text_inputs, **kwargs):
        """
        Generate text with safety checking.

        Args:
            text_inputs: Input text or list of texts to generate from
            **kwargs: Additional generation parameters (max_new_tokens, do_sample, etc.)
                     and safety parameters (safety_level, safety_config)

        Returns:
            Generated text with optional safety metadata
        """
        # Ensure safety is initialized before generation
        self._ensure_safety_initialized()

        # Call parent pipeline
        return super().__call__(text_inputs, **kwargs)

    def _forward(self, model_inputs, **generate_kwargs):
        """
        Forward pass with safety configuration.

        This method adds safety_config to the generation parameters.
        """
        # Extract safety config from generate_kwargs
        safety_config = generate_kwargs.pop("safety_config", self.safety_config)

        # Add safety config to generation if enabled
        if safety_config.enabled:
            generate_kwargs["safety_config"] = safety_config

        # Call parent forward
        return super()._forward(model_inputs, **generate_kwargs)

    def postprocess(
        self,
        model_outputs,
        return_type=None,
        clean_up_tokenization_spaces=None,
        return_safety_metadata=False
    ):
        """
        Postprocess outputs with optional safety metadata.

        Args:
            model_outputs: Outputs from model generation
            return_type: Type of return format (from parent class)
            clean_up_tokenization_spaces: Whether to clean up tokenization spaces
            return_safety_metadata: Whether to include safety metadata in output

        Returns:
            Processed outputs with optional safety information
        """
        # Call parent postprocess
        records = super().postprocess(
            model_outputs,
            return_type=return_type,
            clean_up_tokenization_spaces=clean_up_tokenization_spaces
        )

        # Add safety metadata if requested
        if return_safety_metadata and self.safety_config.enabled:
            # Check generated text for safety violations
            for record in records:
                generated_text = record.get("generated_text", "")

                if self._safety_checker is not None:
                    safety_result = self._safety_checker.check_safety(generated_text)
                    record["safety_metadata"] = {
                        "is_safe": safety_result.is_safe,
                        "confidence": safety_result.confidence,
                        "violations": [
                            {
                                "category": v.category,
                                "confidence": v.confidence,
                                "severity": v.severity
                            }
                            for v in safety_result.violations
                        ] if self.safety_config.return_violations else []
                    }

        return records
```


## 7. Error Handling & Edge Cases

### Graceful Degradation

```python
class SafeTextGenerationPipeline(TextGenerationPipeline):
    # ... existing methods ...

    def _ensure_safety_initialized(self):
        """Initialize safety with graceful degradation."""
        if self._safety_initialized:
            return

        if not self.safety_config.enabled:
            self._safety_initialized = True
            return

        try:
            # Attempt to initialize safety checker
            if "toxicity" in self.safety_config.checkers:
                from transformers.generation.safety import BasicToxicityChecker
                self._safety_checker = BasicToxicityChecker(
                    model_name=self.safety_config.toxicity_model,
                    threshold=self.safety_config.thresholds.get("toxicity", 0.7),
                    device=self.device
                )
        except ImportError as e:
            logger.warning(
                f"Safety checking dependencies not available: {e}. "
                f"Continuing without safety checks. "
                f"Install with: pip install torch transformers"
            )
            self.safety_config.enabled = False
        except Exception as e:
            logger.error(
                f"Failed to initialize safety checker: {e}. "
                f"Continuing without safety checks."
            )
            self.safety_config.enabled = False

        self._safety_initialized = True
```

### Edge Cases Handled

1. **Safety model unavailable**: Gracefully disable safety with warning
2. **Invalid safety configuration**: Clear error message with valid options
3. **Empty prompts**: Handle appropriately without crashing
4. **Very long prompts**: Truncate or handle according to model limits
5. **Batch processing with mixed safety results**: Handle per-item metadata
6. **Device mismatches**: Ensure safety model on same device as generation model

## 9. Performance Considerations

### Lazy Loading Strategy

- Safety models loaded only when needed (first generation call)
- Avoids unnecessary model loading overhead
- Reduces memory footprint when safety disabled

### Caching Integration

- Leverages existing safety cache from Stage 2
- Configurable cache sizes based on safety level
- Efficient for repeated/similar generations

### Performance Targets

- **Initialization overhead**: <2 seconds for safety model loading
- **Generation overhead**: <20% compared to standard TextGenerationPipeline
- **Memory overhead**: <500MB for safety model (loaded once, reused)
- **Batch processing**: Linear scaling with batch size

## 13. Migration from Stage 2

For users currently using Stage 2 direct integration:

**Before (Stage 2 direct usage)**:
```python
from transformers import AutoModelForCausalLM, AutoTokenizer
from transformers.generation.safety import SafetyConfig

model = AutoModelForCausalLM.from_pretrained("gpt2")
tokenizer = AutoTokenizer.from_pretrained("gpt2")
safety_config = SafetyConfig.create_preset("moderate")

inputs = tokenizer("Hello", return_tensors="pt")
outputs = model.generate(**inputs, safety_config=safety_config)
text = tokenizer.decode(outputs[0])
```

**After (Stage 3 pipeline)**:
```python
from transformers import pipeline

pipe = pipeline("safe-text-generation", model="gpt2", safety_level="moderate")
result = pipe("Hello")
text = result[0]["generated_text"]
```

Both approaches remain supported - Stage 3 adds convenience without removing functionality.
