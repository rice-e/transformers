# Stage 2: Generation Integration Implementation

## 1. Executive Summary

This document defines **Stage 2** of the Safe Generation feature implementation, focusing on integrating the core safety infrastructure built in Stage 1 with the transformers generation pipeline. This stage enables actual blocking of harmful content during text generation.

**Important**: This document represents a complete stage of development. The phases listed below (Phase 1, 2, 3, 4) are implementation steps to complete this stage, not separate stages requiring new documents.

**Scope**: Integration with LogitsProcessor, StoppingCriteria, and GenerationConfig systems.
**Goal**: Enable real-time safety checking during `model.generate()` calls with blocking capability.
**Timeline**: 12-16 hours across 4 phases.

## 2. Problem Statement

- ✅ Basic toxicity detection is functional (`BasicToxicityChecker`)

- **Secondary**: Seamless integration with existing generation parameters
- **Non-Goal**: Advanced safety actions (revision, reranking) - just detect and block

### Integration Challenges
1. **Performance**: Safety checks must not significantly impact generation speed
2. **Compatibility**: Must work with all generation modes (greedy, sampling, beam search)  
3. **User Experience**: Clear, actionable error messages when content is blocked
4. **Backward Compatibility**: No breaking changes to existing generation API

## 3. Architecture & Design

### Integration Strategy

Stage 2 integrates safety at **two key points** in the generation pipeline:

1. **Token-level safety** (`SafetyLogitsProcessor`): Check partial sequences during generation
2. **Sequence-level safety** (`SafetyStoppingCriteria`): Final safety check before returning results

### Core Components

#### SafetyLogitsProcessor
```python
from transformers.generation.logits_process import LogitsProcessor
from transformers.generation.safety import SafetyChecker, SafetyConfig
import torch
import torch.nn.functional as F

class SafetyLogitsProcessor(LogitsProcessor):
    """
    LogitsProcessor that suppresses unsafe tokens during generation.
    
    This processor checks the current sequence for safety violations and modifies
    token probabilities to prevent generation of unsafe content.
    """
    
    def __init__(
        self,
        safety_checker: SafetyChecker,
        tokenizer,
        safety_config: SafetyConfig,
        check_interval: int = 1,
        suppress_threshold: float = -float('inf')
    ):
        self.safety_checker = safety_checker
        self.tokenizer = tokenizer
        self.safety_config = safety_config
        self.check_interval = check_interval  # Check every N tokens
        self.suppress_threshold = suppress_threshold  # Logit value for suppression
        self._step_count = 0
    
    def __call__(
        self,
        input_ids: torch.LongTensor,
        scores: torch.FloatTensor,
        **kwargs
    ) -> torch.FloatTensor:
        """
        Apply safety filtering to token scores.
        
        Args:
            input_ids: Current sequence tokens [batch_size, seq_len]
            scores: Token logits [batch_size, vocab_size]
            
        Returns:
            Modified scores with unsafe tokens suppressed
        """
        self._step_count += 1
        
        # Only check safety at specified intervals for performance
        if self._step_count % self.check_interval != 0:
            return scores
        
        batch_size = input_ids.shape[0]
        modified_scores = scores.clone()
        
        for i in range(batch_size):
            # Convert current sequence to text
            current_sequence = input_ids[i]
            current_text = self.tokenizer.decode(current_sequence, skip_special_tokens=True)
            
            # Check safety of current sequence
            safety_result = self.safety_checker.check_safety(current_text)
            
            if not safety_result.is_safe:
                # Get tokens that would continue unsafe content
                unsafe_token_ids = self._get_unsafe_continuation_tokens(
                    current_text, safety_result
                )
                
                # Suppress unsafe tokens
                if unsafe_token_ids:
                    modified_scores[i, unsafe_token_ids] = self.suppress_threshold
        
        return modified_scores
    
    def _get_unsafe_continuation_tokens(self, current_text: str, safety_result) -> list[int]:
        """
        Identify tokens that would likely continue unsafe content.
        
        This is a simplified implementation - could be enhanced with more 
        sophisticated token-level safety analysis.
        """
        # For now, suppress high-risk tokens when toxicity is detected
        if "toxicity" in [v.category for v in safety_result.violations]:
            # Define tokens commonly associated with toxic content
            # This list should be model-specific and more comprehensive
            toxic_tokens = [
                "hate", "stupid", "idiot", "kill", "die", "worst", "terrible",
                "awful", "horrible", "disgusting", "worthless"
            ]
            
            # Convert to token IDs
            unsafe_ids = []
            for token_text in toxic_tokens:
                try:
                    token_id = self.tokenizer.convert_tokens_to_ids(token_text)
                    if token_id != self.tokenizer.unk_token_id:
                        unsafe_ids.append(token_id)
                except:
                    continue
            
            return unsafe_ids
        
        return []
```

#### SafetyStoppingCriteria
```python
from transformers.generation.stopping_criteria import StoppingCriteria
import torch

class SafetyStoppingCriteria(StoppingCriteria):
    """
    StoppingCriteria that halts generation when unsafe content is detected.
    
    This provides a final safety check before sequences are returned to the user.
    """
    
    def __init__(
        self,
        safety_checker: SafetyChecker,
        tokenizer,
        safety_config: SafetyConfig
    ):
        self.safety_checker = safety_checker
        self.tokenizer = tokenizer
        self.safety_config = safety_config
        self._unsafe_sequences = set()  # Track which sequences are unsafe
    
    def __call__(
        self,
        input_ids: torch.LongTensor,
        scores: torch.FloatTensor,
        **kwargs
    ) -> torch.BoolTensor:
        """
        Check if generation should stop due to safety violations.
        
        Args:
            input_ids: Current sequences [batch_size, seq_len]
            scores: Token scores [batch_size, vocab_size]
            
        Returns:
            Boolean tensor indicating which sequences should stop [batch_size]
        """
        batch_size = input_ids.shape[0]
        should_stop = torch.zeros(batch_size, dtype=torch.bool, device=input_ids.device)
        
        for i in range(batch_size):
            # Skip if already marked as unsafe
            if i in self._unsafe_sequences:
                should_stop[i] = True
                continue
            
            # Convert sequence to text
            sequence = input_ids[i]
            text = self.tokenizer.decode(sequence, skip_special_tokens=True)
            
            # Check safety
            safety_result = self.safety_checker.check_safety(text)
            
            if not safety_result.is_safe:
                self._unsafe_sequences.add(i)
                should_stop[i] = True
                
                # Log safety violation for debugging
                violation_categories = [v.category for v in safety_result.violations]
                logger.warning(
                    f"Generation stopped due to safety violation: {violation_categories}"
                )
        
        return should_stop
```

```python
# Addition to GenerationMixin._get_logits_processor()
def _get_logits_processor(self, generation_config, ...):
    processors = LogitsProcessorList()
    # ... existing processors ...
    
    # Add safety processor if enabled
    if (hasattr(generation_config, 'safety_config') and 
        generation_config.safety_config is not None and 
        generation_config.safety_config.enabled):
        
        safety_processor = self._create_safety_processor(generation_config.safety_config)
        if safety_processor is not None:
            processors.append(safety_processor)
    
    return processors

def _create_safety_processor(self, safety_config: SafetyConfig):
    """Create safety processor from configuration."""
    try:
        from .safety import BasicToxicityChecker
        
        # Create checker based on configuration
        if "toxicity" in safety_config.checkers:
            checker_config = safety_config.get_checker_config("toxicity")
            safety_checker = BasicToxicityChecker(**checker_config)
            
            return SafetyLogitsProcessor(
                safety_checker=safety_checker,
                tokenizer=self.tokenizer,
                safety_config=safety_config,
                check_interval=getattr(safety_config, 'check_interval', 1)
            )
    except Exception as e:
        logger.warning(f"Failed to create safety processor: {e}")
        return None
```

## 7. Performance Considerations

### Optimization Strategies

1. **Lazy Safety Checking**: Only check safety every N tokens (configurable interval)
2. **Caching**: Cache safety results for recently seen sequences
3. **Batch Processing**: Process multiple sequences efficiently
4. **Early Exit**: Stop checking once a violation is found

### Performance Targets
- **Latency Impact**: <20% increase in generation time when safety enabled
- **Memory Impact**: <10% additional memory usage
- **Throughput**: Maintain >80% of baseline tokens/second

### Monitoring & Metrics
```python
# Safety performance tracking
@dataclass
class SafetyMetrics:
    total_generations: int = 0
    blocked_generations: int = 0
    avg_safety_check_time_ms: float = 0.0
    safety_check_calls: int = 0
    
    @property
    def block_rate(self) -> float:
        return self.blocked_generations / max(1, self.total_generations)
```

## 8. Error Handling & Edge Cases

### Graceful Degradation
```python
def _create_safety_processor(self, safety_config: SafetyConfig):
    """Create safety processor with graceful degradation."""
    try:
        # Attempt to create safety processor
        return SafetyLogitsProcessor(...)
    except ImportError:
        logger.warning("Safety dependencies not available, skipping safety checks")
        return None
    except Exception as e:
        logger.error(f"Failed to create safety processor: {e}")
        if safety_config.strict_mode:  # Hypothetical strict mode
            raise
        return None
```

### Edge Cases Handled
1. **Empty sequences**: Skip safety checks gracefully
2. **Very long sequences**: Truncate for safety checking
3. **Model loading failures**: Degrade gracefully or fail clearly
4. **Device mismatches**: Ensure tensors are on correct device
5. **Tokenization errors**: Handle special tokens and encoding issues
