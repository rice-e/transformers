# Stage 1: Core Safety Infrastructure Implementation

## 1. Executive Summary

This document defines **Stage 1** of the Safe Generation feature implementation, focusing on establishing the foundational safety infrastructure for HuggingFace Transformers. 

**Important**: This document represents a complete stage of development. The phases listed below (Phase 1, 2, 3, 4) are implementation steps to complete this stage, not separate stages requiring new documents. This phase creates the minimal viable safety system that all future safety features will build upon, following the principle of **simple, clear foundations over complex systems**.

**Scope**: Core safety abstractions, basic toxicity detection, and configuration system.
**Goal**: Establish a testable, extensible foundation without overengineering.
**Timeline**: 10-13 hours across 4 phases.

## 2. Problem Statement

### Current State
- Zero safety infrastructure exists in transformers for text generation
- No standardized way to check generated content for harmful material
- Developers must implement safety checks externally with inconsistent approaches
- Missing foundation for systematic safety feature development

### Phase 1 Objectives
- **Primary**: Create core safety abstractions and basic toxicity detection
- **Secondary**: Establish patterns for configuration, testing, and extensibility
- **Non-Goal**: Complex safety actions, pipeline integration, or multiple checker support

### Core Abstractions

#### SafetyChecker Abstract Base Class
```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import List, Union, Dict, Any, Optional

@dataclass
class SafetyViolation:
    """Represents a single safety violation detected in text."""
    category: str                    # e.g., "toxicity", "bias", "pii"
    confidence: float               # 0.0 to 1.0
    severity: str = "medium"        # "low", "medium", "high", "critical"
    description: str = ""           # Human-readable description
    span: Optional[tuple[int, int]] = None  # Character span if applicable

@dataclass  
class SafetyResult:
    """Result of safety checking operation."""
    is_safe: bool
    confidence: float               # Overall confidence in safety assessment
    violations: List[SafetyViolation]
    metadata: Dict[str, Any]        # Checker-specific information

class SafetyChecker(ABC):
    """Abstract base class for all safety checkers."""
    
    @abstractmethod
    def check_safety(
        self, 
        text: Union[str, List[str]], 
        **kwargs
    ) -> Union[SafetyResult, List[SafetyResult]]:
        """Check text(s) for safety violations.
        
        Args:
            text: Single text string or list of texts to check
            **kwargs: Checker-specific parameters
            
        Returns:
            SafetyResult for single text, List[SafetyResult] for multiple texts
        """
        pass

    @property
    @abstractmethod
    def supported_categories(self) -> List[str]:
        """Return list of safety categories this checker supports."""
        pass
        
    def get_config(self) -> Dict[str, Any]:
        """Return checker configuration for serialization."""
        return {"checker_type": self.__class__.__name__}
```

#### BasicToxicityChecker Implementation
```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch
import torch.nn.functional as F

class BasicToxicityChecker(SafetyChecker):
    """Toxicity checker using unitary/toxic-bert model."""
    
    def __init__(
        self, 
        model_name: str = "unitary/toxic-bert",
        threshold: float = 0.7,
        device: Optional[str] = None
    ):
        self.model_name = model_name
        self.threshold = threshold
        self.device = device or ("cuda" if torch.cuda.is_available() else "cpu")
        
        # Load model and tokenizer
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModelForSequenceClassification.from_pretrained(model_name)
        self.model.to(self.device)
        self.model.eval()
    
    @property
    def supported_categories(self) -> List[str]:
        return ["toxicity"]
    
    def check_safety(
        self, 
        text: Union[str, List[str]], 
        **kwargs
    ) -> Union[SafetyResult, List[SafetyResult]]:
        """Check text for toxicity using toxic-bert model."""
        if isinstance(text, str):
            return self._check_single_text(text, **kwargs)
        else:
            return [self._check_single_text(t, **kwargs) for t in text]
    
    def _check_single_text(self, text: str, **kwargs) -> SafetyResult:
        """Check single text for toxicity."""
        # Tokenize and run inference
        inputs = self.tokenizer(
            text, 
            return_tensors="pt", 
            truncation=True, 
            max_length=512,
            padding=True
        ).to(self.device)
        
        with torch.no_grad():
            outputs = self.model(**inputs)
            probabilities = F.softmax(outputs.logits, dim=-1)
            
        # Extract toxicity probability (assuming binary classification)
        toxicity_score = probabilities[0][1].item()  # Toxic class probability
        
        is_safe = toxicity_score < self.threshold
        violations = []
        
        if not is_safe:
            violations.append(SafetyViolation(
                category="toxicity",
                confidence=toxicity_score,
                severity=self._get_severity(toxicity_score),
                description=f"Detected toxic content with {toxicity_score:.2%} confidence"
            ))
        
        return SafetyResult(
            is_safe=is_safe,
            confidence=max(toxicity_score, 1.0 - toxicity_score),
            violations=violations,
            metadata={
                "model_name": self.model_name,
                "toxicity_score": toxicity_score,
                "threshold": self.threshold
            }
        )
    
    def _get_severity(self, score: float) -> str:
        """Determine severity based on toxicity score."""
        if score >= 0.95:
            return "critical"
        elif score >= 0.85:
            return "high"
        elif score >= 0.75:
            return "medium"
        else:
            return "low"
    
    def get_config(self) -> Dict[str, Any]:
        return {
            "checker_type": "BasicToxicityChecker",
            "model_name": self.model_name,
            "threshold": self.threshold,
            "device": self.device
        }
```

#### SafetyConfig Configuration System
```python
from dataclasses import dataclass, field
from typing import Dict, Any, Optional, List

@dataclass
class SafetyConfig:
    """Configuration for safety checking in text generation."""
    
    # Checker configuration
    enabled: bool = False
    checkers: List[str] = field(default_factory=lambda: ["toxicity"])
    thresholds: Dict[str, float] = field(default_factory=lambda: {"toxicity": 0.7})
    
    # Model configuration
    toxicity_model: str = "unitary/toxic-bert"
    device: Optional[str] = None
    
    # Output configuration
    return_violations: bool = False
    return_metadata: bool = False
    
    def to_dict(self) -> Dict[str, Any]:
        """Convert to dictionary for serialization."""
        return {
            "enabled": self.enabled,
            "checkers": self.checkers,
            "thresholds": self.thresholds,
            "toxicity_model": self.toxicity_model,
            "device": self.device,
            "return_violations": self.return_violations,
            "return_metadata": self.return_metadata
        }
    
    @classmethod
    def from_dict(cls, config_dict: Dict[str, Any]) -> "SafetyConfig":
        """Create from dictionary."""
        return cls(**config_dict)
    
    def validate(self) -> None:
        """Validate configuration parameters."""
        if not isinstance(self.enabled, bool):
            raise ValueError("enabled must be a boolean")
            
        if not all(isinstance(t, float) and 0.0 <= t <= 1.0 for t in self.thresholds.values()):
            raise ValueError("All thresholds must be floats between 0.0 and 1.0")
            
        supported_checkers = {"toxicity"}  # Expandable in future phases
        if not all(c in supported_checkers for c in self.checkers):
            unsupported = set(self.checkers) - supported_checkers
            raise ValueError(f"Unsupported checkers: {unsupported}")
```

## 7. Error Handling & Edge Cases

### Model Loading Failures
```python
class BasicToxicityChecker(SafetyChecker):
    def __init__(self, model_name: str = "unitary/toxic-bert", **kwargs):
        try:
            self.tokenizer = AutoTokenizer.from_pretrained(model_name)
            self.model = AutoModelForSequenceClassification.from_pretrained(model_name)
        except Exception as e:
            raise RuntimeError(
                f"Failed to load toxicity model '{model_name}'. "
                f"Please ensure the model exists and you have internet connectivity. "
                f"Original error: {e}"
            )
```

## 8. Documentation & Examples

### Basic Usage Example
```python
from transformers.generation.safety import BasicToxicityChecker, SafetyConfig

# Simple usage
checker = BasicToxicityChecker(threshold=0.7)
result = checker.check_safety("This is a test message")

if result.is_safe:
    print("Content is safe!")
else:
    print(f"Found {len(result.violations)} safety violations")
    for violation in result.violations:
        print(f"- {violation.category}: {violation.description}")

# Configuration-driven usage  
config = SafetyConfig(
    enabled=True,
    checkers=["toxicity"],
    thresholds={"toxicity": 0.8},
    return_violations=True
)

checker = BasicToxicityChecker(threshold=config.thresholds["toxicity"])
texts = ["Hello world!", "This is inappropriate content"]
results = checker.check_safety(texts)

for text, result in zip(texts, results):
    print(f"'{text}': {'SAFE' if result.is_safe else 'UNSAFE'}")
```
